# 2027 国考襄阳及周边岗位分析

本项目用于辅助筛选适合计算机科学与技术本科应届生的 2027 年国考岗位，并以历史进面最低分数据作谨慎参考。

## 文件说明

- [可视化仪表盘](./index.html)：岗位搜索、地区筛选、历史分数区间和 CSV 导出功能。
- [候选职位清单](./data/2027_guokao_candidates_xiangyang.csv)：2027 年襄阳及周边计算机专业候选岗位、招录人数、资格备注和可比历史分数参考。
- [历年进面最低分记录](./data/xiangyang_tax_history_2019_2025.csv)：选定的襄阳辖区税务单位及少量相邻监管单位历史职位分数。
- [单位年度分数汇总](./data/xiangyang_tax_unit_year_summary.csv)：单位年度职位样本数、中位数、最低分和最高分。
- [方法与限制](./METHODOLOGY.md)：数据处理、预测口径和风险说明。

## 重要说明

历史进面名单通常会在多名考生记录中重复写入同一职位最低面试分数，因此先按每年职位代码去重。职位代码可能跨年更改或重用，故不能直接用职位代码判定不同年份为同一岗位。

税务候选职位的低/中/高预测参考是同一用人司局近年其他岗位最低进面分的 25%、50%、75% 分位数，只表示单位级历史分数分布，不是今年同一职位的精准预测录取线，也不是上岸概率。专业范围、招录人数、考生质量、试题难度和报考热度都会影响结果。

金融监管等需要专业科目考试的岗位单独展示，不混用普通岗位分数预测。英语四级需按岗位要求核对具体分数，团员身份不等于中共党员身份。
