# 2027 国考湖北省岗位筛选与近五年进面参考

网站：<https://stubborn0512.github.io/guokao-fenxi/>

本项目基于用户提供的《中央机关及其直属机构2027年度考试录用公务员招考简章》、以及压缩包内2021—2025年职位最低进面分工作簿，筛选湖北全省适合“计算机科学与技术本科应届生、共青团员、男性”的候选岗位。

## 本版统计

- 主清单：114个职位，合计235个招录名额。
- 另有1个要求CET-6通过或成绩达到公告门槛的职位（2个名额）暂列为“待核验/不计入主清单”，因为当前未确认该条件。
- 另剔除3个对本科专业进一步限定为非计算机科学与技术的职位，合计4个名额。
- 主清单中10个职位有明确CET-4≥425/710或等效成绩门槛；6个职位有指定城市户籍或生源要求。两类条件重叠后，共13个职位必须核验硬性条件。
- 历史窗口为2021—2025，共清洗84,294条职位年度记录。

## 文件

- `data/hubei_candidates_2027.csv`：湖北全省候选岗位与分数参考。
- `data/annual_reference_2021_2025.csv`：候选岗位逐年参考分、匹配层级和样本口径。
- `data/condition_audit_2027.csv`：硬性条件待核验项与排除岗位。
- `METHODOLOGY.md`：筛选规则、分数口径、审计和限制说明。

## 2021—2025 湖北税务逐岗位报名/过审人数补充数据

- [合并后的五年逐岗位数据（含核验来源）](data/offcn_hubei_tax_2021_2025/offcn_hubei_tax_positions_2021_2025_enriched.csv)：共 2,339 条职位年度记录；2021—2024 年逐岗位过审人数来自中公列表，2025 年逐岗位“合格人数”由华图公开职位表补充，且标注字段来源。
- [2025 华图原始职位记录](data/offcn_hubei_tax_2021_2025/offcn_hubei_tax_huatu_2025.csv)：537 条，保留岗位代码、用人司局、职位名称、报名人数、合格人数和原始来源。
- [2025 跨来源匹配审计](data/offcn_hubei_tax_2021_2025/offcn_hubei_tax_huatu_2025_match_audit.csv)：逐岗记录匹配方式，并比较中公与华图的报名人数。
- [五年补数与覆盖率报告](data/offcn_hubei_tax_2021_2025/offcn_hubei_tax_huatu_2025_enrichment_report.json)：包含各年度过审字段覆盖率和数据源说明。

**口径提醒：** 中公的 2025 职位列表逐岗显示“报考人数”，过审汇总为 87,202，但详情入口有登录判断。因此，合并文件的 2025 “过审人数”不是中公提供的逐岗字段，而是华图公开职位表的“合格人数”。537 条职位均按职位代码、用人司局、职位名称精确匹配；中公与华图的报名人数有 384 条不一致，说明平台统计快照或口径存在差异。不要把两家平台的报名人数当作同一时点的数据进行直接比较。数据用于历史参考，不代表未来考试竞争情况。

## 重要提醒

本表为辅助决策，不能代替官方资格审查。已知“通过英语四级”不一定等于达到CET-4 425分；指定户籍/生源限制需要按本人实际情况核验。历史分数是可比岗位的进面最低分参考，不是预测保证、最终录取分或上岸概率。不同招考系统、考试类别之间不可直接横比。
