# 2027 国考襄阳及周边岗位分析

本仓库用于辅助筛选 2027 年国家公务员考试中，适合计算机科学与技术本科应届毕业生的湖北襄阳及周边岗位，并以历年进面最低分数据提供谨慎的参考区间。

## 文件

- `index.html`：可视化仪表盘，支持候选岗位搜索、地区/类型筛选、导出筛选结果。
- `guokao_dashboard_data.json`：仪表盘使用的结构化数据。
- `data/2027_guokao_candidates_xiangyang.csv`：2027 候选岗位和单位级历史分数参考。
- `data/xiangyang_tax_history_2019_2025.csv`：从历年进面分数表提取、按职位代码去重后的襄阳周边税务岗位样本。
- `data/xiangyang_tax_unit_year_summary.csv`：税务单位年度样本数、中位数、最低分、最高分。
- `METHODOLOGY.md`：筛选口径、预测方法和限制。

## 重要方法说明

1. 历年进面名单常把同一职位的最低进面分重复写在每位进面考生行中。提取时先按每年职位代码去重。
2. 职位代码跨年可能重新分配或岗位条件变化，因此不简单按同一职位代码跨年匹配。
3. 襄阳税务分数区间采用同一用人司局近年其他岗位的最低进面分布，主要展示 25%、50%、75% 分位数。它不是同一职位预测分数，也不是录取分数线。
4. 金融监管等需专业科目考试的岗位单独标注，不与普通岗位的历史分数混合预测。
5. 2027 年实际报名竞争度会影响结果；历史分数不可保证未来分数或上岸概率。
6. 最终报考资格以官方招考简章、报考指南和招录机关解释为准。
