## 匹配规则
历史表按“招录机关+用人司局+招考职位+职位代码”复合键去重。不能仅凭职位代码匹配，不能将同一单位其他职位的分数当成同岗分数。空白值表示未找到符合严格规则的记录。资格条件历史字段不完整，即使职位标识相同也不能自动视为完全同条件。

## 分数来源与限制
2019–2025 历史分数来自用户上传的年度面试名单/最低进面分表；2026 年部分分数来自数据表内逐条标注的第三方公开分数汇总页面。2026 分数配有资格画像可比性判断。不要把不具备可比性的同标识分数当成今年预测线。金融监管岗有专业科目，和税务职位不混合比较。

只保存岗位分析派生数据，不上传原始整包。
